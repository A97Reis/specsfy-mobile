# Especialistas mobile para TDD orientado pelo BDD

Use o especialista da plataforma mobile para escolher runner, doubles, bancos em
memória e comandos compatíveis:

- **Android / KMP / CMP**: `specsfy-specialist-android`, `specsfy-specialist-kmp`
  e `specsfy-specialist-cmp` (JUnit, MockK, Turbine, Compose UI Test);
- **iOS**: `specsfy-specialist-ios` (Swift Testing `@Test`, `XCTest`);
- **Flutter**: `specsfy-specialist-flutter` (`flutter test`, `testWidgets`, `blocTest`);
- **React Native / Ionic**: `specsfy-specialist-react-native` e
  `specsfy-specialist-ionic` (Jest, Vitest, React Native Testing Library, Maestro);
- **acessibilidade**: `specsfy-specialist-mobile-accessibility`;
- **persistência e RLS**: `specsfy-specialist-mobile-persistence` e
  `specsfy-specialist-supabase`.

Nenhum especialista pode substituir RED observado ou inventar comportamento.
